# Opus CV

CV intelligence built on recruiter research. Upload a CV for a free score, unlock the full audit for $1, then repair it ($5) or rebuild it on a premium template ($15).

Everything runs in the browser: the CV is never uploaded to a server.

- `index.html` is the whole site (styles, scoring engine and the Opus Studio).
- `assets/` holds the logo and icon.

Business settings (contact email, WhatsApp, payment links) are in the `CONFIG` block near the end of `index.html`.
